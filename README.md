# Лупа / Magnifier

Камера телефона как увеличительное стекло. Офлайн, без рекламы, без сбора данных, без Google Play Services.

## Собрать APK без компьютера (GitHub Actions)

1. Создайте пустой репозиторий на github.com.
2. Загрузите в него все файлы проекта (включая скрытую папку `.github`).
3. Вкладка **Actions** → сборка «Build APK» запустится сама (или кнопка **Run workflow**).
4. Через ~5 минут откройте завершённый запуск → внизу **Artifacts** → `Lupa-apk`.
5. Скачайте zip на телефон, распакуйте, откройте `app-release.apk` и разрешите установку из этого источника.

## Собрать в Android Studio

1. File → Open → папка проекта. Дождитесь синхронизации Gradle.
2. Телефон по USB с включённой отладкой → кнопка Run, или
   Build → Build App Bundle(s) / APK(s) → Build APK(s).
3. Release-APK: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`.

Release сейчас подписывается debug-ключом — годится для личной установки.
Для Google Play и RuStore нужен свой upload key (см. `app/build.gradle.kts`).

## Что проверить на телефоне

- Зум: кнопки «−»/«+», слайдер, щипок, кнопки громкости.
- Тап по экрану — фокус, долгий тап — фиксация фокуса.
- Стоп-кадр → двойной тап, мини-карта, «Сохранить» (альбом Pictures/Lupa), «Поделиться».
- Фильтры и «Тонкая настройка»; после перезапуска выбранный фильтр сохраняется.
- Фронтальная камера + «Подсветка» (белая рамка).
- Плитка: шторка → карандаш → перетащить «Лупа» в быстрые настройки.
- Долгое нажатие на иконку → «С фонариком».
- Свернуть приложение — индикатор камеры гаснет.
